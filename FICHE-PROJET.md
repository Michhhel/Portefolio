# Fiche projet : à copier, remplir et m'envoyer (un message par projet)

```
Projet (nom) :
Période · organisation :
Contexte (2-3 phrases : quel problème, pour qui ?) :
Ton rôle précis :
Démarche (3 à 5 étapes) :
Résultats (3 max, « chiffre : libellé », ex. « 32 : ménages enquêtés ») :
Ce que tu en as retenu (1 phrase) :
Outils utilisés (ils s'allumeront dans le réseau des compétences) :
Liens publics (dépôt GitHub, démo, rapport PDF) :
Visuels (1 à 3 captures ou graphiques SANS donnée sensible ; fichier + légende) :
Confidentialité : publiable tel quel / à anonymiser / non publiable
```

## Ce qui change à l'affichage
- **Aujourd'hui (mode aperçu)** : la carte porte un badge « Détails à venir » ; la page montre contexte, rôle, ce que tu as fait, chiffres clés, outils, et un encadré « détails à venir ».
- **Après ajout (mode complet)** : le badge et l'encadré disparaissent ; s'ajoutent la démarche en étapes numérotées, tes résultats, un enseignement, les boutons Code source / Démo / Rapport, une galerie de visuels ; dans le réseau des compétences, tes outils renvoient vers le projet.
- Technique : dans `data/content.json`, remplir `st`, `rs`, `ls`, `lk`, `img`, `tools` du projet, puis `"det": 1`.
